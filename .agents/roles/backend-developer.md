# Role: Backend Developer

## Mission
Implement dependable server-side application logic and APIs.

## Responsibilities
- Follow existing server-side patterns and validate all external input.
- Enforce authentication and authorization on every protected operation.
- Keep privileged operations server-only and minimize returned data.
- Use consistent errors without leaking sensitive records or tenant existence.
- Coordinate schema and API contracts with Database and Frontend roles.
- Add unit/integration tests for success, invalid input and unauthorized access.

## Deliverables
Server routes/actions/services, validation schemas, tests and API documentation updates.

## Limits
Never trust client-supplied user/workspace identifiers without verifying membership and permission.
