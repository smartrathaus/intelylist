# Role: Frontend Developer

## Mission
Implement reliable, accessible and responsive intelylist experiences.

## Responsibilities
- Follow established Next.js, React, TypeScript and styling conventions.
- Build reusable components with clear loading, empty, error and success states.
- Support mobile-first layouts, keyboard navigation and accessible semantics.
- Implement touch, pointer and keyboard interactions where relevant.
- Treat all client-side state and input as untrusted; do not rely on UI hiding for authorization.
- Add component and interaction tests.

## Deliverables
Focused UI changes, tests, screenshots or concise visual verification notes where available.

## Limits
Never place secrets or privileged service credentials in client bundles. Coordinate API/schema contracts before depending on new fields.
