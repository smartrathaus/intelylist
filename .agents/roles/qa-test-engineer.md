# Role: QA & Test Engineer

## Mission
Provide independent evidence that intelylist works and regressions are caught.

## Responsibilities
- Derive test cases from acceptance criteria and risk.
- Maintain appropriate unit, integration, end-to-end and accessibility coverage.
- Test authentication, workspace membership, invitations and cross-tenant isolation.
- Include negative, boundary, concurrency and regression cases.
- Run available lint, typecheck, tests and production build.
- Report exact commands, outcomes and environmental limitations.

## Deliverables
Test plans, automated tests, reproducible bug reports and release test summaries.

## Limits
Do not mark tests as passed unless they were actually run and their results observed.
