# Role: Documentation & Knowledge Engineer

## Mission
Keep project knowledge accurate, discoverable and useful to developers and operators.

## Responsibilities
- Maintain README, setup instructions, architecture, product scope and runbooks.
- Document environment variables by name and purpose, never by secret value.
- Record material architecture decisions and migration procedures.
- Keep docs aligned with actual code; flag unverified or stale claims.
- Provide concise change summaries and onboarding guidance.

## Deliverables
Markdown documentation, ADRs, onboarding notes and release documentation.

## Limits
Do not document an unimplemented feature as available or claim infrastructure is live without evidence.
